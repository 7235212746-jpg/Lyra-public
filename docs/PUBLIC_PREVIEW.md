## 科学口径

1. PROCAR/XML 投影表示所用投影定义下的局域贡献。显示的百分比以已解析投影为分母，不代表完整波函数概率或 DFT 误差。
2. 自动带边使用 VASP 占据数和真实采样能量。缺失或无法可靠解释的数据会显示原因；展宽下的部分占据可能导致无法判定。
3. 高对称路径上的 VBM/CBM 和带隙只覆盖已采样 k 点，不能证明整个布里渊区的严格全局极值。
4. 直接/间接标签比较周期等价 k 点及能量容差内的简并候选；它不等同于光学跃迁允许性判断。
5. 手动两点工具报告所选点的能量差，不自动将任意两点解释为材料带隙。
6. 双计算中的相似候选不证明波函数身份相同，SOC/非 SOC 之间尤其需要独立物理判断。
7. Combined 默认使用 DOS/SCF 的费米能级对齐显示。金属性判断仍使用 Band 数据自身的能量参考。
8. 当前费米面使用完整规则网格和周期边界，不自动展开对称约化网格，未提供轨道着色。
9. OUTCAR 导出的磁矩是位点投影磁矩，投影数值与完整晶胞总磁矩的定义不同。
10. 质量报告覆盖已实现的证据规则；没有警告不代表数值已经对截断能、k 网格或方法选择完成收敛验证。

## 远程与手机预览

远程连接依赖用户自行安装 WinSCP，并核验目标服务器的主机指纹。可选择仅供当前会话使用的凭据，也可使用 Windows 当前用户 DPAPI 加密保存；仓库中不附带任何用户凭据。

原地解析的代码和自动化测试已包含，但本次公开发布没有新增真实 Linux 服务器端到端验收。远端 Python 与科学库需要符合环境预检要求。

手机服务监听本机回环地址。跨网络访问需用户配置自己的 Tailscale Serve；当前移动后端接受已授权目录上的标准 Band、DOS 和 Combined，不支持投影设置。
